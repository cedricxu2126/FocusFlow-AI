# FocusFlow AI – AI Usage Log

This document records how AI assistance was used throughout the planning, development, debugging, testing, and documentation of FocusFlow AI.

The entries summarize the AI-assisted development process. The developer reviewed the suggestions, made implementation decisions, modified code, and tested the resulting functionality.

## Interaction 1 – Project Planning

**Prompt Summary:** Requested help developing an idea for an AI-assisted productivity and task management application.

**AI Assistance:** Helped define the FocusFlow AI concept, identify its main features, establish project objectives, and select an appropriate technology stack.

**Developer Modifications:** Selected the final application concept and determined which features would be included in the project.

**Final Result:** Established the FocusFlow AI project plan and development direction.

## Interaction 2 – Project Structure and Database Design

**Prompt Summary:** Requested guidance setting up a Flask application and organizing its project files.

**AI Assistance:** Recommended a modular folder structure and a SQLite database design for storing tasks and application information.

**Developer Modifications:** Created the project directories, Python modules, database files, and initial application structure.

**Final Result:** Established the Flask application foundation and SQLite database.

## Interaction 3 – Task Management Implementation

**Prompt Summary:** Requested help implementing task creation, editing, completion, filtering, and deletion.

**AI Assistance:** Provided guidance for Flask API routes, SQL operations, and JavaScript functionality.

**Developer Modifications:** Integrated the code into the task routes, HTML template, and JavaScript files. Tested the task management features and corrected issues.

**Final Result:** Implemented a working task management system with persistent database storage.

## Interaction 4 – Planner and Recommendation Logic

**Prompt Summary:** Requested help developing a planner that organizes tasks based on priority and deadlines.

**AI Assistance:** Suggested a rule-based scoring system that considers task priority, due-date urgency, and estimated workload.

**Developer Modifications:** Integrated the recommendation logic into the planner route and connected it to the frontend using JavaScript.

**Final Result:** Created a planner that organizes pending tasks and provides workload insights without requiring a paid AI API.

## Interaction 5 – Break Activities

**Prompt Summary:** Requested help implementing a break timer and recreational brain teaser activities.

**AI Assistance:** Provided guidance for the break timer, interactive questions, answer reveal functionality, and navigation between questions.

**Developer Modifications:** Integrated the JavaScript and HTML functionality and corrected an issue involving the break duration input.

**Final Result:** Implemented a working break timer and interactive brain teaser section.

## Interaction 6 – Productivity Statistics

**Prompt Summary:** Requested help creating a statistics page to display task completion and focus-session information.

**AI Assistance:** Suggested SQL queries and calculations for total tasks, completed tasks, pending tasks, completion percentage, and daily focus time.

**Developer Modifications:** Created the statistics route and connected database results to the statistics template.

**Final Result:** Created a statistics dashboard displaying productivity information.

## Interaction 7 – User Settings

**Prompt Summary:** Requested help implementing customizable focus and break durations.

**AI Assistance:** Provided guidance for creating a settings database table, validating user input, and saving preferences through a Flask API.

**Developer Modifications:** Integrated the settings page, JavaScript save functionality, and database updates. Tested that settings persisted after refreshing and navigating between pages.

**Final Result:** Implemented persistent user preferences that control the focus and break timers.

## Interaction 8 – Visual Redesign

**Prompt Summary:** Requested a futuristic cyberpunk visual redesign using neon blue, pink, and green colors.

**AI Assistance:** Recommended a dark interface, neon accent colors, futuristic fonts, glowing effects, and responsive styling.

**Developer Modifications:** Replaced the original stylesheet and refreshed the application to verify that the redesign did not interfere with existing functionality.

**Final Result:** Implemented a consistent cyberpunk-inspired interface across the application.

## Interaction 9 – Project Documentation

**Prompt Summary:** Requested help preparing project documentation for the course submission.

**AI Assistance:** Provided structured content for the README, project requirements, and development documentation.

**Developer Modifications:** Reviewed and added the documentation files to the project.

**Final Result:** Prepared project documentation describing the application, its features, technology stack, requirements, and development process.

---

## Overall AI Usage Reflection

AI assistance was used throughout the software development lifecycle, including project planning, system design, coding, debugging, testing, and documentation.

AI suggestions were reviewed and integrated into the project by the developer. The developer made decisions about the application's scope, modified the suggested code, resolved implementation issues, and tested the completed features.

The project demonstrates how AI tools can assist software development while the developer remains responsible for implementation decisions, verification, and the final application.
